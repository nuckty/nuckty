# Демо nuckty

Интерактивная витрина, собранная через публичный CLI nuckty. По пять страниц на русском и английском показывают Markdown/GFM, точные исходники примеров, галерею с лайтбоксом, сетку, типографику, живой редактор BEMJSON и реальные файлы сборки. У логотипа есть варианты для светлой и тёмной темы; отдельный квадратный favicon подготовлен на основе его знака. `blocks/page/package.json` задаёт CommonJS для `page.bemdecl.js`; шаблоны загружаются через декларацию бандла страницы.

Редактор и настоящие примеры галереи и сетки доступны сразу на главной. Страницы разделов дают подробные инструкции и точные исходники.

## Локальная разработка

Нужен Node.js 24+. Выполните `npm ci` и `npm run build` в корне репозитория: демо использует пакеты workspace того же коммита. Русский результат — в `site/`, английский — в `site-en/`. Редактор использует `@nuckty/core/browser` и изолированный iframe.

При установленном nginx `npm run serve` запускает демо на `http://localhost:8092`, `npm run stop` останавливает его. Для сайта на `http://localhost:8091` запустите просмотр `nuckty-site`. Английский просмотр: `npm run serve:en`, адрес `http://localhost:8094`; остановка — `npm run stop:en`. Публичные домены — demo.nuckty.ru и demo.nuckty.com; для локальных ссылок между языками и сайтом используйте `npm run build:preview`. Контакт: vitaly@harisov.name.

## Проверка витрины

Выполните `npm run build`, `npm run lint`, `npm test` и `npm run validate`. Проверяются ссылки, якоря, ассеты, хэши, сжатые копии, галерея, типографика и sandbox. Для Nu Html Checker нужна Java. Локальное расширение `ext/showcase.ts` регистрирует конструкции showcase/example/playground и создаёт `build-files.txt` перед стадией manifest; снимок не включает сам себя и итоговый манифест.

## Проверка опубликованных пакетов

Запустите `npm run test:package` с доступом к публичному npm. Скрипт устанавливает из публичного реестра все одиннадцать официальных пакетов в версиях из манифестов workspace в отдельный каталог с пробелами и Unicode, проверяет registry URL и integrity в lock-файле, публичные типы и CLI, затем собирает HTML и ассеты gallery/grid. Пока новые версии распространяются по реестру, установка повторяется до десяти минут. При ошибке временный каталог сохраняется, а его путь выводится.

## Публикация

Workflow выпуска репозитория после публикации в npm запускает проверку опубликованных пакетов, затем собирает демо из коммита выпуска и публикует обе языковые версии. Пуш без выпуска демо не публикует.
