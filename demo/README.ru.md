# nuckty-demo

Интерактивная витрина, собранная через публичный CLI nuckty. По пять страниц на русском и английском показывают Markdown/GFM, точные исходники примеров, галерею с лайтбоксом, сетку, типографику, живой редактор BEMJSON и реальные файлы сборки. Для светлой и тёмной темы используется указанный новый логотип; отдельный квадратный favicon подготовлен на основе его знака. `blocks/package.json` задаёт CommonJS для `.bemdecl.js`; шаблоны загружаются через декларацию бандла.

Редактор и настоящие примеры галереи и сетки доступны сразу на главной. Страницы разделов дают подробные инструкции и точные исходники.

## Локальная разработка

Нужен Node.js 24+. Выполните `npm ci`, затем `npm run build`: точные версии Nuckty загружаются из публичного npm. Русский результат — в `site/`, английский — в `site-en/`. Редактор использует `@nuckty/core/browser` и изолированный iframe.

При установленном nginx `npm run serve` запускает демо на `http://localhost:8092`, `npm run stop` останавливает его. Для сайта на `http://localhost:8091` запустите просмотр соседнего nuckty-site. Английский просмотр: `npm run serve:en`, адрес `http://localhost:8094`; остановка — `npm run stop:en`. Публичные домены — demo.nuckty.ru и demo.nuckty.com; для локальных ссылок между языками и сайтом используйте `npm run build:preview`. Контакт: vitaly@harisov.name.

## Проверка витрины

Выполните `npm run build`, `npm run lint`, `npm test` и `npm run validate`. Проверяются ссылки, якоря, ассеты, хэши, сжатые копии, галерея, типографика и sandbox. Для Nu Html Checker нужна Java. Локальное расширение `ext/showcase.ts` регистрирует конструкции showcase/example/playground и создаёт `build-files.txt` перед стадией manifest; снимок не включает сам себя и итоговый манифест.

## Проверка пакетов

Запустите `npm run test:package` с доступом к публичному npm. Скрипт устанавливает все одиннадцать опубликованных пакетов версии `1.0.0-beta1` в отдельный каталог с пробелами и Unicode, проверяет registry URL и integrity в lock-файле, публичные типы и CLI, затем собирает HTML и ассеты gallery/grid. Архивы соседних исходников не создаются. При ошибке временный каталог сохраняется, а его путь выводится.

## Проверка чистой установки

Запустите `npm run test:clean-install`. Скрипт копирует только исходники демо, устанавливает зависимости по его manifest и lock-файлу через `npm ci`, затем собирает оба языка без соседних репозиториев. При ошибке временный каталог сохраняется, после успеха удаляется.

## Обновление опубликованных пакетов

`.github/workflows/update-packages.yml` получает версии фиксированного набора официальных пакетов из публичного канала npm `beta` или `latest`. Выбранные точные версии хранятся в `config/config-packages.json`. При несовместимых peer dependencies ядра обновление останавливается. После чистой установки и проверок потребителя workflow создаёт коммит с версиями и lock-файлом, затем явно запускает CI с деплоем; неизменившийся набор не создаёт коммит. Workflow публикации пакета запускает обновление после проверки реестра.
