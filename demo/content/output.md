# Файлы текущей сборки

`npm run build` вызывает `nuckty build` и создаёт по пять страниц: русские в `site/`, английские в `site-en/`. Ниже можно открыть страницы, стили, скрипт и изображения, а также посмотреть размеры их сжатых копий.

## От файла Markdown к адресу

Таргет — один собираемый сайт. Его конфигурация задаёт язык, домен и выходной каталог. Карта сайта связывает исходные файлы с адресами страниц.

```ts
targets: {
    default: {
        configDir: 'config/',
        outDir: 'site/',
        lang: 'ru',
        host: 'demo.nuckty.ru',
    },
}
```

```yaml
sitemap:
  - Возможности nuckty [/, index.md, { layout: "landing" }]
  - Markdown и ссылки [/markdown, markdown.md]
  - Галерея и сетка [/media, media.md]
  - Живой движок [/playground, playground.md]
  - Результат сборки [/output, output.md]
```

## Из чего состоит артефакт

| Файлы | Назначение |
| --- | --- |
| `html/` | Страницы после обработки Markdown и шаблонов |
| `css/` и `js/` | Бандлы стилей и скриптов с именами по содержимому |
| `svg/` и каталоги растровых форматов | Изображения с хэшированными именами |
| `brotli/` и `gzip/` | Сжатые копии страниц и ассетов |
| `.htaccess` | Конфигурация Apache |
| `manifest.json` | Размеры и хэши файлов для публикации |

Конфигурация nginx находится отдельно, в `.build/nginx.conf`. Её использует локальный просмотр; это не файл внутри `site/`.

## Собрать, открыть, проверить

Выполняйте команды из каталога демо. Для просмотра нужен nginx, для проверки HTML — Java.

```bash
npm run build
npm run serve
npm run validate
npm run stop
```

`build` предоставляет ядро. `serve` и `validate` добавлены расширениями. Публикация по FTP/FTPS доступна через `deploy-ftp` после настройки сервера; демо не запускает её автоматически.

Другие расширения готовят AVIF/WebP, получают репозитории контента или добавляют видео. Эти возможности описаны в каталоге расширений сайта nuckty; в этом демо они не выполняются.

## Общие блоки для двух языков

И демо, и сайт документации nuckty собирают русскую и английскую версии из общих блоков. У них отдельные карты сайта и выходные каталоги. Переключение языка ведёт к тому же адресу на другом сайте, а обработчик документа выводит ссылки `hreflang`.
