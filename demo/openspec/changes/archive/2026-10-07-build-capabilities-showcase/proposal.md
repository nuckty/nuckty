# Capabilities showcase

## Why
The existing demo contains only a Hello page. Visitors need executable examples of the actual engine and packaged extensions.

## What Changes
Expand the consumer into a Russian feature gallery with source/result panels, a live BEMJSON renderer, Markdown, gallery, grid, typography and build-output examples. Retain the existing package-boundary checks.

## Impact
Changes demo content, blocks, configuration and consumer checks. Existing engine APIs and package contracts stay intact.
