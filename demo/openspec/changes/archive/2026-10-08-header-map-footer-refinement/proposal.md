# Refine header controls and footer alignment

## Why
Theme controls have an unnecessary border, burger and close are separate icons, footer links do not share a stable alignment, and the article source link sits outside the footer. The website menu focuses a link and exposes collapsible groups instead of linked section headings.

## What Changes
Remove theme borders, animate the existing burger lines into a cross with the reference timing, and align footer groups and links. Move documentation source links into the footer. On the website, focus the search input from the menu, keep the same animated toggle visible, show fixed map groups with linked overview headings, and align empty-result text with the primary map links.

## Impact
Consumer root/CSS and website search controller. No publication.
