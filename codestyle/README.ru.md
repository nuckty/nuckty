# nuckty-codestyle

> Единый свод правил для всех репозиториев `nuckty-*`.

Проект хранит общие соглашения о коде, документации, тестах и процессе работы. `AGENTS.md` каждого проекта ссылается на общие правила и дополняет их локальными требованиями.

## Состав

- [AGENTS.md](AGENTS.md) — общие правила проектов.
- [GLOSSARY.md](GLOSSARY.md) и [GLOSSARY.ru.md](GLOSSARY.ru.md) — парные справочники английской и русской терминологии.
- `.ai/` — инструкции для повторяющихся задач проекта, в том числе для редактирования документации.

При изменении определения правьте оба глоссария. Перед релизом сверяйте терминологию и язык с общими правилами.
