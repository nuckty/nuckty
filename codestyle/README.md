# nuckty-codestyle

> The shared rulebook for every `nuckty-*` repository.

This project holds common code, documentation, testing, and workflow conventions. Each project's `AGENTS.md` references the shared rules and adds local requirements.

## Contents

- [AGENTS.md](AGENTS.md) — common project rules.
- [GLOSSARY.md](GLOSSARY.md) and [GLOSSARY.ru.md](GLOSSARY.ru.md) — paired English and Russian terminology.
- `.ai/` — reusable guidance for project workflows, including documentation editing.

Edit both glossaries when a definition changes. Check terminology and language against these rules before a release.
