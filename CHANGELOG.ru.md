# История изменений

## 1.0.0-rc.0

- Все официальные пакеты разрабатываются в монорепозитории nuckty и выпускаются вместе через Changesets. Содержимое пакетов и публичный API не изменились.
- `@nuckty/core` экспортирует типы `Plugin` и `Root`, которые используют Markdown-расширения, и объявляет зависимость `@types/mdast`: опубликованные декларации разрешаются без зависимостей разработки.
- Демо, документация и общие правила находятся в монорепозитории; сайт остаётся отдельным потребителем пакетов из реестра.

## 1.0.0-beta3

- Явный `tag` в BEMJSON имеет приоритет над декларациями nu, включая функции режима `tag`. Значение `tag: false` сохраняет фрагмент без обёртки; отсутствующий или неопределённый тег берётся из шаблона.
- Селекторы блока применяются только к узлам блока. Именованные и wildcard-селекторы элементов применяются к элементам независимо, в том числе в структурных режимах `content` и `wrap`.
- Шаблоны сайта и демо используют прямые декларации блоков без предикатов, компенсирующих эти ошибки движка.
- Официальные расширения объявляют совместимость с `@nuckty/core@1.0.0-beta3`.

## 1.0.0-beta2

- Workflow GitHub Release каждого пакета публикует проверенный архив через npm OIDC trusted publisher, затем обновляет совместимые точные зависимости сайта и демо из реестра.
- Peer-зависимости официальных расширений указывают на `@nuckty/core@1.0.0-beta2`.
- Этот выпуск использует автоматическую публикацию; её результат проверяется в workflow выпуска и CI потребителей.

## 1.0.0-beta1

> We call its Beta, coz it's betta then nothin

Первый кандидат бета-версии. Запись описывает подготовленный набор исходников и не объявляет публикацию пакетов в npm или выкладку сайтов.

### Ядро

- Шаблонизатор BEMJSON на TypeScript и ESM: двухпроходная обработка, композиция шаблонов nu.ts и сериализация HTML с опусканием необязательных тегов.
- Явная карта сайта, контент Markdown, переиспользуемые уровни блоков, декларации зависимостей и несколько таргетов сборки.
- Программируемый конвейер: сборка CSS и JavaScript, хешированные ассеты, изображения, Brotli/Gzip, манифесты и конфигурация хостинга nginx/Apache.
- Общий контракт расширений: конвейер, Markdown, уровни блоков, команды CLI и генерация документа. CLI загружает конфигурацию и шаблоны TypeScript.

### Расширения

- Отдельные пакеты блоков root, gallery и grid.
- Пакеты Markdown для видео и русской типографики.
- Команды предпросмотра и остановки сервера, проверки HTML, подготовки внешнего контента, конвертации изображений и публикации по FTP.

### Документация и потребители

- Английская и русская документация, общие правила разработки и словарь терминов.
- Сайт nuckty с локальным поиском Orama, светлой и тёмной темами и подсветкой TanStack при сборке.
- Интерактивное демо, самостоятельные стартовые архивы и отдельно поддерживаемый исходник логотипа SVG.

### Проверки и границы выпуска

- Исходники сопровождаются тестами пакетов, проверкой ссылок и конфигурацией CI. Совместимые версии пакетов для CI закрепляются SHA коммитов.
- У пакетов общая версия 1.0.0-beta1. Демо и сайт остаются приватными потребителями npm; публикация исходников, публикация npm-пакетов и выкладка сайтов выполняются отдельно.
