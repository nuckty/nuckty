# Pipeline-расширения

Каталог расширений типа `pipeline` — тех, что добавляют [стадии сборки](../how/ext/pipeline.ru.md). Страницы размещаются непосредственно под `/ext/pipeline/<имя>`, без дополнительных тематических подразделов.

## Как это работает

[Pipeline](../how/pipeline.ru.md)-расширение регистрирует стадию или хук через `env.pipeline`:

```ts
export function register(env) {
    env.pipeline.after('html', searchIndexStage);
}
```

Полный контракт — в [руководстве по pipeline-расширениям](../how/ext/pipeline.ru.md).

## Реестр

Официальных pipeline-расширений пока нет. Возможные расширения:

- Поисковый индекс (Orama, SQLite FTS5, lunr) — стадия после [HTML](../out/html.ru.md), читает содержимое страниц.
- Собственная конфигурация [хостинга](../out/hosting.ru.md) — стадия в `emit`, генерирует конфигурацию Caddy или иного сервера.
- Подготовка [изображений](../out/images.ru.md) — `before('images', ...)`: создаёт варианты до хэширования и копирования семейства.
- XML-карта сайта для поисковых систем или RSS/Atom — стадия создаёт XML из [дерева карты сайта](../how/sitemap.ru.md). Ядро копирует готовый `robots.txt` из каталога конфигурации таргета; `sitemap.xml` должно создать расширение.
