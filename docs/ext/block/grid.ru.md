# @nuckty/ext-block-grid

Многоколоночная раскладка контента. Пакет объединяет блок `grid` и конструкцию markdown-разметки `:::grid`: синтаксис и реализация раскладки поставляются вместе.

## Типы

Пакет совмещает два типа расширений через единый `register(env)`:

- [block](../../how/ext/block.ru.md) — блок `grid` через `env.levels`.
- [markdown](../../how/ext/markdown.ru.md) — конструкция `:::grid` через `env.markdown`.

## Конструкция markdown-разметки

Автор пишет:

```md
:::grid
Первая колонка.

Вторая колонка.

Третья колонка.
:::
```

Каждый дочерний абзац с текстом или изображением и каждый HTML-блок становятся ячейкой `grid__item` и выводятся как обычное содержимое: ссылки, выделение, код и изображения сохраняют разметку, а изображения используют хэшированные файлы. Дочерние списки и заголовки вызывают ошибку. Пустой контейнер раскрывается в содержимое. Без расширения движок обрабатывает Markdown внутри директивы обычным образом.

## Поведение

- **Адаптивная сетка** — ячейки выкладываются в несколько колонок через CSS блока; число колонок подстраивается под ширину экрана.
- **Без внешних зависимостей** — раскладка держится на CSS блока, без сторонних библиотек CSS и JS.

## Установка

Пример продолжает быстрый старт со стандартным обработчиком `@nuckty/ext-block-root`. Добавьте новое расширение в `ext` глобального `config/config-nuckty.ts`, сохранив остальные записи. Если обработчик документа собственный, оставьте его вместо `@nuckty/ext-block-root`.

Установите расширение из npm в распакованном [стартовом проекте](../../how/start.ru.md):

```bash
npm install --save-exact @nuckty/ext-block-grid@1.0.0-rc.4
```

```ts
import { defineNucktyConfig } from '@nuckty/core';

export default defineNucktyConfig({
    targets: { main: { configDir: 'config/', outDir: 'site/' } },
    ext: ['@nuckty/ext-block-root', '@nuckty/ext-block-grid'],
});
```

После этого конструкция `:::grid` работает в любом `.md`, а блок `grid` добавьте в bemdecl бандла — он подключится по [зависимостям](../../how/blocks/deps.ru.md).

## Переопределение

Блок `grid` переопределяется как любой другой: поместите свой `blocks/grid/grid.nu.ts` на более поздний [уровень](../../how/blocks/levels.ru.md).
