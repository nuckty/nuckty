# Расширения документа

Расширение документа регистрирует обработчик через `env.document`: тот получает данные страницы и возвращает [BEMTree](../how/bemjson.ru.md) документа. Контракт и пример — в [руководстве](../how/ext/document.ru.md).

## Доступная реализация

[`@nuckty/ext-block-root`](block/root.ru.md) совмещает расширение документа и блоков. Пакет регистрирует стандартный обработчик и добавляет уровень с [шаблоном](../how/templates.ru.md) `root`. Отдельных пакетов с именем `@nuckty/ext-document-*` в текущем семействе нет.

Сайт может подключить собственный локальный обработчик вместо root. Для каждой сборки нужен ровно один обработчик.
