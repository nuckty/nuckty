# nuckty-docs

Здесь лежит исходный контент Markdown документации генератора статических сайтов [nuckty](https://github.com/nuckty/nuckty). Конфигурации проекта-потребителя и скриптов сборки сайта в этом репозитории нет.

## Структура

| Каталог | О чём                                                                                     |
|---------|-------------------------------------------------------------------------------------------|
| `how`   | Как пользоваться: модель данных, шаблоны, карта сайта, конвейер сборки, блоки, расширения |
| `out`   | Результат сборки: HTML, ассеты, изображения, сжатие, конфигурация хостинга                |
| `ext`   | Каталог расширений экосистемы nuckty                                                      |
| `why`   | Архитектурные решения: почему сделано так, а не иначе                                     |

## Репозитории экосистемы

nuckty — семейство независимых репозиториев, а не монорепозиторий. Общие правила задаёт `nuckty-codestyle`. Подробности — в [решении о репозиториях](why/repos.ru.md).

| Репозиторий | Роль |
|---|---|
| `nuckty` | Ядро — только `nuckty build [target]`. Не зависит от `nuckty-*`. |
| `nuckty-codestyle` | Единый свод правил `AGENTS.md` для всех репозиториев. |
| `nuckty-demo` | Демо для быстрого старта. |
| `nuckty-docs` | Только контент Markdown; конфигурации сборки сайта здесь нет. |

Сами расширения (`nuckty-ext-*`) собраны в [каталоге расширений](ext/index.ru.md).

## Проверка исходных ссылок

Запустите `node scripts/check-source-links.mjs`, чтобы проверить, что локальные ссылки Markdown ведут на существующие исходные файлы. Проверка пропускает блоки и фрагменты кода.
