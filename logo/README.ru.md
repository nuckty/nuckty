# nuckty-logo

Канонический исходник логотипа SVG для nuckty 1.0.0-beta1.

Исходный файл — `nuckty-logo-black-transparent.svg`. Тёмные варианты, подсветка при наведении и favicon поддерживаются в проектах сайтов. Настройки оптимизации находятся в `config/config-svgo.js`.

## Оптимизация SVG

Установите зависимости и оптимизируйте готовые SVG:

```sh
npm ci
npm run optimize
```

Команда использует `config/config-svgo.js`. Редактируемые исходники
(`_source.svg`) и построительные сетки (`_grid.svg`) исключены из обработки.
