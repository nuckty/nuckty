# @nuckty/ext-block-gallery

> **Галерея изображений с лайтбоксом — конструкция `:::gallery` и блок `gallery`.**

Пакет для [nuckty](https://github.com/nuckty/nuckty), объединяющий два типа расширений в одном `register(env)`:

- **block** — блок `gallery` и вспомогательный блок `lightbox` через `env.levels`;
- **markdown** — конструкция `:::gallery` через `env.markdown.directive`.

## Конструкция markdown-разметки

```md
:::gallery
![Подпись A](a.png)
![Подпись B](b.png)
![Подпись C](c.png)
:::
```

Обработчик директивы собирает изображения контейнера, подставляет хэшированные имена из `image-mapping.json` (общий механизм разрешения ссылок движка) и строит дерево блока `gallery`. Контейнер без изображений раскрывается в обычное содержимое.

## Поведение

- **Сетка** — CSS блока раскладывает изображения адаптивной сеткой; число колонок подстраивается под ширину экрана.
- **Лайтбокс** — клик по изображению открывает полноразмерную версию в блоке `lightbox`. Реализация собственная, на чистом JS: движок не подключает фронтенд-библиотеки. Закрытие — Esc, клик по фону или кнопка.
- **Отложенная загрузка** — у первого изображения каждой галереи нет `loading=lazy`; у остальных этот атрибут есть. Обработчик не определяет, видна ли галерея на первом экране.

## Как подключить

```bash
npm install @nuckty/ext-block-gallery
```

Пример продолжает быстрый старт со стандартным обработчиком `@nuckty/ext-block-root`. Добавьте новое расширение в `ext` глобального `config/config-nuckty.ts`, сохранив остальные записи. Если обработчик документа собственный, оставьте его вместо `@nuckty/ext-block-root`.

```ts
import { defineNucktyConfig } from '@nuckty/core';

export default defineNucktyConfig({
    targets: { main: { configDir: 'config/', outDir: 'site/' } },
    ext: ['@nuckty/ext-block-root', '@nuckty/ext-block-gallery'],
});
```

И добавьте `gallery` и `lightbox` в bemdecl бандла страницы, например `blocks/page/page.bemdecl.js`, — тогда шаблоны, стили и скрипт попадут в сборку.

## Переопределение

Поместите свой `blocks/gallery/gallery.nu.ts` на более поздний уровень для замены шаблона. Для изменения стилей добавьте `blocks/gallery/gallery.css` на этот уровень: CSS объявленного блока объединяется со всех уровней. В bemdecl перечисляются имена блоков, а не файлы CSS.

## Спецификация

Поведение закреплено в спецификации openspec `ext-block-gallery` (`openspec/specs/ext-block-gallery/spec.md`).
