# @nuckty/ext-block-root

> **Обёртка страницы — блок `root`.**

Расширение документа и блоков для [nuckty](https://github.com/nuckty/nuckty). Регистрирует стандартный обработчик документа и поставляет блок `root`, который оборачивает контент страницы в `<html>`, `<head>` и `<body>`.

## Что добавляет

`register(env)` регистрирует обработчик через `env.document` и добавляет каталог `blocks/` пакета через `env.levels`. Обработчик преобразует подготовленный движком `DocumentData` в `{ block: 'root', props, content }`.

Блок использует режим `wrap` и формирует документ. Движок не знает имя `root` и его разметку: он передаёт `DocumentData` зарегистрированному обработчику и сериализует возвращённое дерево BEMJSON.

Данные страницы блок читает из `n.props`:

- `page` — URL, заголовок, исходный файл и метаданные карты сайта;
- `content` — BEMTree с уже сериализованным содержимым в узле `raw`;
- `assets` — карты CSS, JS, изображений и видео;
- `lang` — язык текущего таргета;
- `alternates` — `Map<lang, { url, title, host }>` для hreflang.

Стандартный блок выводит title, viewport, ссылки hreflang, все непустые бандлы CSS и бандлы JS с `defer`. Переопределение сайта может выбрать нужные бандлы, добавить метаданные и разместить внутренние блоки. Сам движок не выбирает блок по `page.layout`.

## Контракт имён

Расширение занимает только имя `root`. Пространство имён `page*` (`page`, `page-index`, `page-about`, …) остаётся за сайтом — коллизий с ядром нет.

## Как подключить

```bash
npm install @nuckty/ext-block-root
```

Добавьте расширение в `ext` глобального `config/config-nuckty.ts`, сохранив остальные записи. Оно регистрирует обработчик документа; перед подключением удалите регистрацию другого обработчика:

```ts
import { defineNucktyConfig } from '@nuckty/core';

export default defineNucktyConfig({
    targets: { main: { configDir: 'config/', outDir: 'site/' } },
    ext: ['@nuckty/ext-block-root'],
});
```

Добавьте `root` в bemdecl каждого бандла документа, например `blocks/page/page.bemdecl.js`.

## Переопределение

Поместите свой `blocks/root/root.nu.ts` на более поздний уровень (например, в `blocks/` сайта) — движок выберет его по приоритету уровней. Так меняют структуру `<head>`, мета-теги или счётчики, не создавая ответвление пакета.

## Спецификация

Поведение закреплено в спецификации openspec `ext-block-root` (`openspec/specs/ext-block-root/spec.md`).
