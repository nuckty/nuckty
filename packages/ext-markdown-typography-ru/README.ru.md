# @nuckty/ext-markdown-typography-ru

> **Русская типографика для markdown — тире не отрывается от слова.**

Markdown-расширение для [nuckty](https://github.com/nuckty/nuckty). Применяет русскую типографику при преобразовании mdast, до моста mdast → BEMJSON: обходит текст и выравнивает пробелы вокруг тире (`—`, U+2014 — русское «тире») — неразрывный пробел перед ним и обычный после, по русскому типографическому правилу (`<слово> — <текст>`).

Сайт подключает это расширение, только если нужна русская типографика. Без него ядро выводит текст дословно, без типографических замен, — англоязычный сайт его просто не указывает.

## Что добавляет

remark-плагин mdast, регистрируемый через `env.markdown.use(...)`. Это только markdown-расширение — без блока, без команды CLI, без стадии сборки.

Расширение нормализует пробелы вокруг уже стоящего тире:

- неразрывный пробел перед тире — тире не повиснет в начале строки;
- обычный пробел после — каноническая форма «слово — текст»;
- правило применяется к любым исходным пробелам: с обеих сторон, с одной, вовсе без пробелов между буквами.

Само тире расширение не создаёт: дефис в тире не превращается, короткое тире (`–`) не трогается. Тире в тексте пишет автор.

Код пропускается: `code` и `inlineCode` — отдельные типы узлов mdast, поэтому преобразование в них не заходит — код остаётся как написан.

## Как подключить

Пример продолжает быстрый старт со стандартным обработчиком `@nuckty/ext-block-root`. Добавьте новое расширение в `ext` глобального `config/config-nuckty.ts`, сохранив остальные записи. Если обработчик документа собственный, оставьте его вместо `@nuckty/ext-block-root`.

```ts
import { defineNucktyConfig } from '@nuckty/core';

export default defineNucktyConfig({
    targets: { main: { configDir: 'config/', outDir: 'site/' } },
    ext: ['@nuckty/ext-block-root', '@nuckty/ext-markdown-typography-ru'],
});
```

Ядро ничего не знает о типографике. Преобразование выполняется только для потребителей, которые подключили расширение.

## Контракт

`register(env: NucktyEnv)` подключает `remarkTypographyRu` через `env.markdown.use`. Пакет экспортирует этот remark-плагин и текстовую функцию `applyRussianTypography`.

## Спецификация

Поведение закреплено в спецификации openspec `ext-markdown-typography-ru` (`openspec/specs/ext-markdown-typography-ru/spec.md`): регистрируется как преобразование mdast, тире и неразрывные пробелы, код пропускается, подключается отдельно.
